## Part 3 – SPI Signals

SPI uses four communication lines:

| Signal | Full Form | Function |
|--------|-----------|----------|
| MOSI | Master Out Slave In | Data from Master to Slave |
| MISO | Master In Slave Out | Data from Slave to Master |
| SCK | Serial Clock | Clock signal generated by Master |
| SS/CS | Slave Select | Selects Slave Device |

---

# 🔄 SPI Communication Process

1. Master selects the slave using SS/CS pin.
2. Master generates the clock signal.
3. Data is transmitted through MOSI line.
4. Slave sends data through MISO line.
5. Data transfer occurs on every clock pulse.
6. Communication stops when SS becomes inactive.

---

# 🧠 SPI Features

- High-speed communication
- Full duplex data transfer
- Simple hardware structure
- No fixed data frame format
- Supports multiple slave devices
- Low software overhead

| Feature | SPI | UART |
|---------|-----|------|

# ⚙ SPI Hardware in 8051

The standard 8051 microcontroller does not have built-in SPI hardware.

SPI communication is implemented using:

- GPIO pins
- Software SPI (Bit Banging)

---

# 🔌 SPI Pin Configuration in 8051

Example:

| 8051 Pin | SPI Function |
|----------|--------------|
| P1.0 | MOSI |
| P1.1 | MISO |
| P1.2 | SCK |
| P1.3 | SS/CS |

---

# 🧠 SPI Registers Concept

Since classic 8051 does not contain SPI hardware, SPI is controlled using GPIO.

Important registers used:

## Port Registers

Used for controlling SPI pins.

```c
P1 = data;
````

---

## Data Direction

Controls input/output operation.

Example:

```c
MOSI = 1;
SCK  = 0;
```

---

# ⚙ Software SPI Initialization

```c
void SPI_Init()
{
    MOSI = 0;
    SCK  = 0;
    SS   = 1;
}
```

---

# 🔄 SPI Data Transmission

Transmission steps:

1. Pull SS LOW.
2. Send 8 bits through MOSI.
3. Generate clock pulse.
4. Release SS HIGH.

Example:

```c
void SPI_Send(unsigned char data)
{
    int i;

    SS = 0;

    for(i=0;i<8;i++)
    {
        MOSI = (data & 0x80) ? 1 : 0;

        SCK = 1;

        data <<= 1;

        SCK = 0;
    }

    SS = 1;
}
```

# 📌 Key Takeaways

* SPI is a synchronous serial communication protocol.
* SPI uses four lines: MOSI, MISO, SCK, and SS.
* SPI follows Master-Slave architecture.
* Master generates the clock signal.
* SPI supports full-duplex communication.
* Classic 8051 does not have built-in SPI hardware.
* SPI can be implemented using GPIO pins (Bit Banging).
* SPI provides faster communication compared to UART and I²C.
* SPI is widely used for sensors, EEPROM, ADC, DAC, and displays.
