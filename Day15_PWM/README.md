# 🎚️ Day 15 – PWM (Pulse Width Modulation)

Welcome to **Day 15** of my **Embedded Firmware Engineer Learning Journey**.

Today, I learned **PWM (Pulse Width Modulation)**, a fundamental technique used in embedded systems to control power, brightness, speed, and position using a purely digital signal.

PWM works by rapidly switching a digital output ON and OFF, and varying the proportion of time it stays ON (called the duty cycle) within a fixed period. This creates an analog-equivalent effect — such as dimming an LED or controlling motor speed — without needing an actual DAC.

PWM is one of the most widely used techniques in real-world embedded systems, from motor drivers to power supplies to servo control in robotics.

### 🔹 PWM Duty Cycle & Formulas

For a PWM signal with ON time **Ton** and total period **T**:

```text
Duty Cycle (%) = (Ton / T) × 100
```

```text
T = Ton + Toff
Frequency (Hz) = 1 / T
```

```text
Vavg = Duty Cycle × Vsupply
```

For example, with a 5V supply and 50% duty cycle:

```text
Vavg = 0.5 × 5V = 2.5V (effective average)
```

## 🔌 PWM in Microcontrollers

### 8051

The standard **8051 microcontroller does not contain a dedicated PWM peripheral**.

Therefore, PWM must be generated in **software**, by toggling a GPIO pin ON and OFF using calculated timer/delay values to control Ton and Toff.

### STM32

Modern STM32 microcontrollers provide **dedicated hardware PWM channels** through their timer peripherals (TIM1, TIM2, TIM3, etc.).

Important concepts include:

* Auto-Reload Register (ARR) – sets PWM period/frequency
* Capture/Compare Register (CCR) – sets duty cycle
* Prescaler (PSC) – divides timer clock
* PWM Mode 1 / PWM Mode 2

```text
Duty Cycle (%) = (CCR / ARR) × 100
```

# 🔧 Software PWM Generation with 8051

Since the 8051 has no built-in PWM hardware, the signal is generated by manually toggling an output pin using timed delays.

### Basic PWM Generation Sequence

```text
Set PWM Pin HIGH
      ↓
Delay for Ton (based on duty cycle)
      ↓
Set PWM Pin LOW
      ↓
Delay for Toff (remaining period)
      ↓
Repeat Continuously
```

## 🔌 PWM Pin Connections (8051)

| Signal              | 8051 Pin | Function                            |
| ------------------- | -------- | ------------------------------------ |
| PWM Output          | P1.0     | Software-generated PWM signal        |
| Motor Direction     | P1.1     | H-Bridge direction control (optional)|
| Speed UP Button     | P3.0     | Increase speed level (active low)    |
| Speed DOWN Button   | P3.1     | Decrease speed level (active low)    |
| ADC Data Bus         | P0       | Potentiometer reading (via ADC0808)  |
| ADC Control Lines   | P2.0–P2.3| ALE, START, EOC, OE (ADC0808)        |

> ⚠️ **Software PWM accuracy depends on delay loop timing**, so delay values should be tuned against an oscilloscope for precise frequency and duty cycle control.

# 🎚️ Servo Motor PWM Control

Servo motors are controlled using a **fixed 20ms period**, where the pulse width within that period determines the shaft angle.

```text
Digital Angle Command
        ↓
   Map to Pulse Width
        ↓
  Generate 20ms Period Pulse
        ↓
   Servo Shaft Rotates
```

### Servo Pulse Width Reference

| Angle | Pulse Width |
| ----- | ------------ |
| 0°    | ~1.0 ms      |
| 90°   | ~1.5 ms      |
| 180°  | ~2.0 ms      |

# ⚖️ PWM vs DAC

| Feature          | PWM                          | DAC                             |
| ----------------- | ----------------------------- | --------------------------------- |
| Output Type       | Digital (switched)           | True Analog                       |
| Hardware Needed   | Timer + GPIO                 | Dedicated DAC IC/peripheral       |
| Smoothing         | Needs filter for true analog | Native analog output              |
| Common Use        | Motor/LED control            | Audio/waveform generation         |
| Cost/Complexity   | Simple, low-cost             | More complex hardware             |
