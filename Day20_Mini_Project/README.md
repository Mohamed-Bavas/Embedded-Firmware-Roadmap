# 🔐 Day 20 – Door Lock System Using Embedded C

Welcome to **Day 20** of my Embedded Firmware Engineer Learning Journey! 🚀

This mini project focuses on developing a **Door Lock System using Embedded C in Keil μVision**. Through this project, I practice programming logic and explore how a door lock system can be implemented using microcontroller-based programming.

## 🎯 Project Objective

- Develop a basic door lock system using Embedded C.
- Practice writing and compiling embedded programs in Keil μVision.
- Understand access control logic.
- Improve microcontroller programming and debugging skills.

## ⚙️ Project Working Principle

1. Initialize the program.
2. Process the input according to the door lock logic.
3. Check the access conditions.
4. Determine whether access should be granted or denied.
5. Display or perform the corresponding result, depending on the implementation.

*The actual functionality depends on the code implemented in `DoorLock.c` and the hardware configuration.*

## ▶️ How to Build the Project

1. Open **Keil μVision**.
2. Create or open your embedded project.
3. Select the appropriate microcontroller for your project.
4. Add `DoorLock.c` to the project.
5. Configure the required project settings.
6. Click **Build** to compile the program.
7. Check the build output for errors and warnings.
8. Test the program using the supported simulation or hardware setup.
