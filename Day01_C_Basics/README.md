## ▶️ How to Compile

```bash
gcc hello_world.c -o hello_world
```

## ▶️ How to Run

### Windows (PowerShell)

```powershell
.\hello_world.exe
```

### Windows (Command Prompt)

```cmd
hello_world.exe
```
